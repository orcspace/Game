# LAST DROP — запуск игры

Это рабочий прототип 3D-шутера в жанре battle royale. Игра на английском. Клиент: HTML, CSS, JavaScript, Three.js. Сервер: Node.js и WebSocket.

## Скачать и запустить на Windows

1. В GitHub нажми **Code → Download ZIP**.
2. Распакуй архив.
3. Установи **Node.js версии 22 или новее** с https://nodejs.org/.
4. Открой **start-windows.bat**. Первый запуск установит зависимости — нужен интернет.
5. В браузере перейди на **http://localhost:3000**. Окно сервера оставь открытым.

На macOS/Linux: `sh start-macos-linux.sh`. Либо в папке проекта выполни `npm ci`, затем `npm start`.

Файл HTML сам по себе игру не запустит: для комнат и боёв нужен сервер. GitHub хранит проект, но не запускает сервер игры.

## Первый матч

Впиши ник, выбери 9 ботов и нажми **CREATE LOBBY → START MATCH**. При желании укажи пароль. После отсчёта нажми **ENTER THE ACTION**, затем **Пробел**, чтобы выпрыгнуть из самолёта. Парашют откроется автоматически; его можно открыть раньше Пробелом.

**WASD** — движение, **Shift** — бег, **мышь** — прицел, **левая кнопка** — огонь, **правая** — приближение. **E** — подобрать, **R** — перезарядить, **H** — аптечка, **1–5** — оружие. **Esc** — освободить курсор.

Для телефона предусмотрены экранные кнопки и джойстик. Используй горизонтальный экран. На реальном телефоне производительность ещё не измерялась.

## Пригласить друзей

Друзьям нужны **адрес того же сервера**, код комнаты и пароль, если ты его установил. Код не заменяет адрес сервера.

В одной Wi-Fi-сети друг может открыть `http://IP-ТВОЕГО-КОМПЬЮТЕРА:3000`, если доступ разрешён брандмауэром. Для игры через интернет проект нужно разместить на сервере с Node.js, поддержкой WebSocket и HTTPS. Настройки запуска и Docker есть в [README.md](README.md).

Комната вмещает до 50 участников. Боты занимают только свободные места. Подключение 50 тестовых клиентов проверяется автоматически, но это не доказательство стабильности 50 человек из разных стран на разных устройствах.

Это первая версия: дома, лут, пять видов оружия, урон, броня, аптечки, зона, боты и победитель. Графика low-poly. По детализации и готовности это пока не PUBG. Аккаунтов, команд, голосового чата, машин и сохранения матчей нет. Перезапуск сервера удаляет комнаты; отключившийся игрок выбывает.
